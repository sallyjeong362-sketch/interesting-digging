# deeply

초·중·고 학생이 관심사에서 출발해 관찰, 근거 찾기, 설명을 연습하는 한국어 웹앱 프로토타입입니다.

## 실행

Node.js 24에서 외부 의존성 없이 실행합니다.

```sh
npm run check
npm run dev
```

기본 포트는 3000이며 `PORT=3001 npm run dev`처럼 변경할 수 있습니다.

## 사용

주제 선택 → 3단계 미션 → 발견 기록 → 별과 배지 획득. 직접 질문을 만들 수도 있습니다. 왼쪽 아래 프로필에서 초·중·고 도움말을 선택합니다. 탐구 및 보상은 localStorage에 저장되며 서버로 전송되지 않습니다. Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다.

## 설계 원칙과 범위

관심에 따른 선택, 작은 단계의 안내, 예상과 관찰의 비교, 근거와 출처 기록, 자기 설명을 탐구 흐름에 반영했습니다. 보상은 기록 행동에 주어지며 내용의 정확성을 자동으로 검증하지 않습니다. 일일 연속 접속 압박, 순위, 유료 보상은 없습니다. 교육 효과를 검증한 제품이나 뇌 기능 진단 도구가 아닙니다.

현재는 고정된 탐구 안내와 로컬 저장을 제공하는 프로토타입입니다. AI 대화, 출처 검증, 계정과 기기 간 동기화, 교사·보호자 기능은 포함하지 않습니다. 실제 학생 대상 운영 전에는 학년별 사용자 검증, 접근성 검토, 개인정보·안전 정책 및 콘텐츠 검수를 별도 진행해야 합니다.
